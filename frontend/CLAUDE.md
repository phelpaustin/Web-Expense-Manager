# Frontend (React 18 + Vite)

Loaded when working under `frontend/`. Commands and cross-cutting rules are in the root `CLAUDE.md`.

## Map
- `frontend/src/api/client.js` – the only place that calls `fetch`; attaches the token, handles 401 expiry.
- `frontend/src/hooks/` – app state and handlers. `useAppData` owns fetched data and `loadAll()`; `useAuth` the session; `use*Handlers` (expense, income, recurring, bills, trip, group, budget) are mutations that call `loadAll(parts)` afterwards, naming only what changed (`PART`, `EXPENSE_PARTS`). Pages are `React.lazy` chunks.
- `frontend/src/components/MobileNav.jsx` + `hooks/useMediaQuery.js` – phone navigation (screen ≤ 760px, `PHONE_QUERY`): `Layout` renders this bottom bar (Dashboard, Spending, a raised Add button, Insights, More) instead of the sidebar, never both, so tests and desktop see only one set of links. Add opens a sheet (expense / bill with items / upload a receipt via `onUploadReceipt`); More holds Income, Recurring, Import, Trips, Settings and Log out. Tests mock `window.matchMedia` (`mobileNav.test.jsx`); without it the layout is the desktop one.
- `frontend/src/pages/SpendingPage.jsx` – the Spending page: a title, an Add menu (expense / bill with items / upload a receipt) and two views, **By receipt** (`BillsPage`) and **All items** (`ExpensesPage`), both with `embedded` so they drop their own title. The view is `?view=receipts|items` (last choice kept in localStorage); `?add=bill` opens All items with the bill form. Old `/expenses` and `/bills` addresses redirect here. Only the active view is mounted; coming back to By receipt calls `bills.reload()`.
- `frontend/src/components/expenses/` – the pieces of the Expenses view (Spending, All items) (add panel, filters, bulk edit, table, row, pager, option lists). They only render; all state and handlers stay in `pages/ExpensesPage.jsx` and arrive as props.
- `frontend/src/App.jsx` – wires hooks to routes; `pages/` are screens, `components/` shared UI. `format.js` formats money. The sidebar is grouped in `Layout.jsx`; Settings has tabs (Account, Spaces & sharing, App data) and opens on `?tab=`, so `/groups` redirects to `/settings?tab=spaces`. Export lives in Settings → App data. The Dashboard keeps the headline numbers and budgets; the analysis panels live on `pages/InsightsPage.jsx` (tabs, opens on `?tab=`; Shops and Prices render inside it with `embedded`; the Report tab is `components/ReportPanel.jsx` + `report.js`, charts by recharts and downloads through `downloadReport` in `api/client.js`). Savings goals live on `pages/SavingsPage.jsx` (+ `components/SavingsGoalCard.jsx`, `savings.js`; sidebar Money group and the phone More sheet). The space picker is `components/ScopePicker.jsx`, shared by both and backed by app state.
